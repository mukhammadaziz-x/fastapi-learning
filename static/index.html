Powerful Features

Everything you need to manage tests securely and analyze student performance effectively.

Fullscreen Monitoring

Enforces fullscreen mode during tests. Automatically detects when students leave fullscreen and tracks violations.

Violation Detection

If a student exits fullscreen more than 3 times, the test automatically fails with a score of 0. Zero tolerance for cheating.

Secure Access Links

Generate unique, time-limited tokens for each student. Links expire after the teacher-defined period.

Time-Bound Tests

Set exact start and end dates. Students can only access tests within the active window defined by the teacher.

Performance Analytics

Real-time score tracking, completion rates, violation logs, and detailed per-student analysis.

Instant Results

Auto-grading for multiple choice questions with instant score calculation and percentage display.

How It Works

Simple 4-step process to create and manage secure tests.

1

Teacher Registers & Creates Test

Sign up as a teacher, create a test with questions, set time limits and the access window (start/end dates).

2

Generate Access Links

Add students and generate unique, time-limited access tokens. Share the link with each student.

3

Student Takes Test in Fullscreen

Students open their unique link, enter fullscreen mode, and answer questions. Violations are tracked in real-time.

4

View Results & Analytics

See scores, violation counts, pass/fail status, and detailed per-question analysis — instantly after submission.
